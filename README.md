# Novel Writer

A distraction-free novel writing application designed for authors and creative writers.

## Features

- **Chapter Management**: Easily create, switch between, and delete chapters
- **Real-time Word & Character Count**: Track your writing progress as you type
- **Auto-save**: Your work is automatically saved to local storage
- **Clean Interface**: Distraction-free writing experience with a beautiful gradient design
- **Export Functionality**: Export your entire novel as a Markdown file
- **Responsive Design**: Works on desktop and mobile devices

## Getting Started

1. Open `index.html` in your web browser
2. Start writing in the text editor
3. Use the "+ New Chapter" button to add chapters
4. Switch between chapters using the dropdown menu
5. Your work is automatically saved to your browser's local storage

## Usage

### Writing
- Click on the text area and start typing
- The chapter title can be edited by clicking on the title field
- Word and character counts update in real-time

### Chapter Management
- **New Chapter**: Click "+ New Chapter" to add a new chapter
- **Switch Chapters**: Use the dropdown menu to navigate between chapters
- **Delete Chapter**: Select a chapter and click "Delete Chapter" (requires confirmation)

### Export Your Novel
- Click the "Export" button to download your entire novel as a Markdown file
- The exported file includes all chapters and total statistics

### Clear All Data
- Click "Clear All" to reset the application (requires double confirmation)

## Technologies Used

- HTML5
- CSS3 (with modern gradients and responsive design)
- Vanilla JavaScript (ES6+)
- Local Storage API for data persistence

## Browser Compatibility

Works in all modern browsers that support:
- Local Storage
- ES6 JavaScript
- CSS Grid and Flexbox
